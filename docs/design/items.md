# Items & Synergien

## Drei-Ebenen-System

```
WEAPON      → bestimmt Angriffsmethode
MODIFIER    → verändert Verhalten
PASSIVE     → verändert Spieler
```

## Synergy Tags

```
fire, burn, projectile, crit, bleed, melee,
summon, freeze, explosion, poison, low_hp,
shield, dash, lifesteal, ice, lightning
```

## Beispiel-Builds

### Berserker
```
Low HP → Damage ↑ → Attack Speed ↑ → Lifesteal → Blood Explosion
```

### Frost Mage
```
Freeze → Frozen enemies +100% damage → Shatter → Area Explosion → Chain Freeze
```

### Summoner
```
Minions → Minion Damage → Minion Count → Minion AS → Sacrifice → Explosion
```

## Synergy Rules

Synergien werden durch Tags erkannt:
- **3 gleiche Tags** = Tier 1 Synergy (+25% Effect)
- **5 gleiche Tags** = Tier 2 Synergy (+50% Effect)
- **7 gleiche Tags** = Tier 3 Synergy (+100% Effect + Unique Bonus)
